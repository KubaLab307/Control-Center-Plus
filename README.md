# Control Centre Plus

A custom macOS Control Centre experience, bringing quick settings and controls together in one clean, convenient interface.

## Overview

Control Centre Plus is a Python-based desktop project designed to create an alternative Control Centre experience for macOS.

Inspired by Apple's design language, it aims to provide a modern, minimal interface with convenient access to frequently used controls.

## Features

- **Menu Bar Integration** – Access Control Centre Plus from the macOS menu bar.
- **Floating Control Panel** – A custom frameless panel.
- **Two-Column Layout** – Organised controls in a compact grid.
- **Custom Interface** – A minimal design inspired by macOS.
- **Settings Access** – A dedicated settings button.
- **Click-Outside Behaviour** – Close the panel by clicking outside it.

## Technology

- Python
- PyQt5
- macOS

## Compatibility

Developed with macOS in mind.

The initial development environment is:

- Intel Mac

## Installation

Clone or download this repository.

Install the required dependency:

```bash
pip install PyQt5
```

Run the application:

```bash
python3 JKControlCentre.py
```
